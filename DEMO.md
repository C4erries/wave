# Wave — руководство по демонстрации

## Быстрый старт

```bash
# Запуск (по умолчанию — full_pipeline)
./scripts/demo.sh

# Или выбрать конкретный сценарий
./scripts/demo.sh chirp_sweep
./scripts/demo.sh noise_band
./scripts/demo.sh dual_channel

# Переключить сценарий без перезапуска
source components/integration/.venv/bin/activate
wave-orchestrator reload --config components/orchestrator/configs/chirp_sweep.yaml

# Остановить всё
./scripts/stop.sh
```

После запуска открываются адреса:

| Страница | URL |
|---|---|
| Главная / Dashboard | http://localhost:8080 |
| Осциллограф + FFT | http://localhost:8080/lab |
| Конструктор пайплайна | http://localhost:8080/constructor |
| Метрики топиков | http://localhost:8080/metrics |
| Список топиков | http://localhost:8080/topics |
| Статус оркестратора | http://localhost:8099/status |

## Сценарии

### `full_pipeline` — базовый (по умолчанию)
Синусоида 1000 Гц → FFT + Stats + Filter(500–1500 Гц) + Threshold(0.8).
Хорошо подходит для первого показа: все 5 типов топиков активны, в /constructor
видна полная цепочка от источника до событий.

### `chirp_sweep` — движущийся спектр ★ самый зрелищный
Частота линейно нарастает от 200 до 8000 Гц (chirp). В /lab видно, как пик на
FFT-графике плавно едет слева направо. Filter обрезает всё вне 2000–6000 Гц.

### `noise_band` — демо фильтра
Белый шум → узкополосный фильтр 900–1100 Гц. В осциллограмме — хаос, после
фильтра — почти чистый синус. Спектр: плоский → узкая игла. Threshold 0.4
редко стреляет при пиках шума.

### `dual_channel` — два источника
440 Гц (нота A) и 660 Гц (квинта) параллельно. В /constructor видна
разветвлённая схема: 2 источника + 4 оператора. В /topics — 6 активных топиков.

## Что скринить и куда

### Для текстовой части курсовой

#### Архитектура системы
- **`/constructor` → вкладка «Схема», сценарий `full_pipeline`**
  DAG из 5 нод: Synth → FFT, Stats, Filter, Threshold. Подпись:
  «Рис. X. Граф обработки сигнала в конструкторе пайплайна».
  Позволяет проиллюстрировать раздел «Архитектура» и принцип stateless-операторов.

- **`/constructor` → вкладка «Схема», сценарий `dual_channel`**
  Разветвлённый граф с двумя ветками. Подпись:
  «Рис. X. Параллельная обработка двух каналов».
  Иллюстрирует масштабируемость и независимость каналов.

#### Брокер и топики
- **`/topics`** (любой сценарий)
  Таблица с живыми топиками, offset'ами, количеством партиций.
  Подпись: «Рис. X. Активные топики брокера Wave-MQ».
  Используется в разделе «Брокер сообщений» или «Реализация».

- **`/topics` → клик на топик `raw.gen.chA`**
  Детальная страница: offset, consumer groups, throughput.
  Подпись: «Рис. X. Детальная информация о топике».

#### Обработка сигналов
- **`/lab` → выбрать `raw.gen.chA` и `spectrum.gen.chA`, сценарий `full_pipeline`**
  Два графика рядом: синусоида и её FFT. Подпись:
  «Рис. X. Визуализация сигнала и спектра в режиме реального времени».

- **`/lab` → `raw.gen.chA` и `filtered.gen.chA`, сценарий `noise_band`**
  Хаотичный шум и почти чистый синус после полосового фильтра.
  Подпись: «Рис. X. Результат применения полосового фильтра (900–1100 Гц)».
  Сильный аргумент для раздела «Оператор Filter».

#### Мониторинг
- **`/metrics`** (сценарий `full_pipeline`)
  Throughput по топикам, латентность, активные consumer groups.
  Подпись: «Рис. X. Метрики производительности пайплайна».

- **`http://localhost:8099/status`** (JSON в браузере или curl)
  Ответ оркестратора: список процессов, статус alive/dead.
  Подпись: «Рис. X. Статус оркестратора (HTTP API)».
  Иллюстрирует раздел «Оркестратор».

### Для презентации (слайды)

**Слайд «Демо — осциллограф» (1 скрин)**
→ `/lab`, сценарий `chirp_sweep`, момент когда пик FFT посередине экрана.
Крупный скрин на весь слайд. Подпись: «Анализ chirp-сигнала в реальном времени».

**Слайд «Конструктор пайплайна» (1–2 скрина)**
→ `/constructor` → вкладка «Схема», сценарий `dual_channel`.
Покажите схему и рядом форму добавления нода. Подпись: «Визуальное конфигурирование».

**Слайд «Фильтрация» (1 скрин)**
→ `/lab`, сценарий `noise_band`, два канала: `raw.gen.chA` (шум) и `filtered.gen.chA` (синус).
Подпись: «Полосовой фильтр 900–1100 Гц: до и после».

**Слайд «Архитектура» (схема, не скрин)**
Нарисуйте схему: `wave-gen → broker → [fft, stats, filter, threshold] → broker → UI`.
Или используйте скрин `/constructor` как основу.

**Слайд «Топики и данные» (1 скрин)**
→ `/topics`, любой сценарий, несколько активных топиков с живыми offset'ами.
Подпись: «Брокер Wave-MQ: 6 активных топиков».

**Слайд «Метрики» (1 скрин)**
→ `/metrics`, полный pipeline.

## Порядок для живого демо (5 минут)

1. `./scripts/demo.sh full_pipeline` — запустить, дождаться статуса.
2. Открыть `/topics` — показать живые топики, растущие offset'ы.
3. Перейти в `/lab` — показать синусоиду и FFT.
4. Переключить сценарий: `wave-orchestrator reload --config .../chirp_sweep.yaml`
5. Вернуться в `/lab` — показать, как пик FFT едет по экрану.
6. Перейти в `/constructor` → «Схема» — показать граф, переключить на `dual_channel`.
7. `/metrics` — throughput, латентность.
8. `./scripts/stop.sh`

## Полезные команды

```bash
# Статус оркестратора

# Посмотреть топики брокера
curl http://localhost:8090/api/topics

# Запустить только Docker-стек (без оркестратора, для скриншотов UI)
docker compose -f deploy/docker-compose.demo.yml up --build
```
