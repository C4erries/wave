# Wave — руководство по демонстрации

## Быстрый старт

```bash
# Запуск (по умолчанию — full_pipeline), Ctrl+C останавливает всё
./scripts/demo.sh

# Или выбрать конкретный сценарий
./scripts/demo.sh chirp_sweep
./scripts/demo.sh noise_band
./scripts/demo.sh multi_signal

# Переключить сценарий без перезапуска
source components/integration/.venv/bin/activate
wave-orchestrator reload --config components/orchestrator/configs/chirp_sweep.yaml

# Остановить всё
Ctrl+C  (или ./scripts/stop.sh из другого терминала)
```

После запуска открываются адреса:

| Страница | URL |
|---|---|
| Главная / Dashboard | http://localhost:8080 |
| Осциллограф + FFT | http://localhost:8080/lab |
| Конструктор пайплайна | http://localhost:8080/constructor |
| Метрики топиков | http://localhost:8080/metrics |
| Список топиков | http://localhost:8080/topics |
| Статус оркестратора | http://localhost:8099/status |

## Сценарии

### `full_pipeline` — базовый (по умолчанию)
Синусоида плавно sweep-ует от **300 до 3000 Гц** за 10 секунд (и обратно).
В `/lab` пик FFT медленно едет слева направо. Фильтр 800–2000 Гц виден на
отдельном графике «Фильтрованный сигнал» — пик появляется когда попадает в
полосу, и исчезает когда выходит за неё. Все 5 типов топиков активны.

### `chirp_sweep` — широкий sweep ★ самый зрелищный
Частота свипирует от **100 до 8000 Гц** за 6 секунд. В `/lab` пик FFT быстро
пересекает весь диапазон. Фильтр 2000–6000 Гц хорошо показывает окно пропускания.

### `noise_band` — демо фильтра
Белый шум → узкополосный фильтр 900–1100 Гц. В осциллограмме — хаос, после
фильтра — почти чистый синус. Спектр: плоский и меняющийся → узкая полоса.
Threshold 0.4 редко стреляет при пиках шума.

### `multi_signal` — два независимых sweep
Два канала с разными диапазонами и скоростями: chA 200–4000 Гц (8 с),
chB 500–6000 Гц (5 с). Пики на спектрах движутся в разном ритме.
В `/constructor` — разветвлённая схема с двумя ветками.

## Что скринить и куда

### Для текстовой части курсовой

#### Архитектура системы
- **`/constructor` → вкладка «Схема», сценарий `full_pipeline`**
  DAG из 5 нод: Synth → FFT, Stats, Filter, Threshold. Подпись:
  «Рис. X. Граф обработки сигнала в конструкторе пайплайна».

- **`/constructor` → вкладка «Схема», сценарий `multi_signal`**
  Разветвлённый граф с двумя ветками. Подпись:
  «Рис. X. Параллельная обработка двух каналов».

#### Брокер и топики
- **`/topics`** (любой сценарий)
  Таблица с живыми топиками, offset'ами, количеством партиций.
  Подпись: «Рис. X. Активные топики брокера Wave-MQ».

- **`/topics` → клик на топик `raw.gen.chA`**
  Детальная страница: offset, consumer groups, throughput.

#### Обработка сигналов
- **`/lab`, сценарий `full_pipeline`**
  Пик FFT едет по экрану + под основными графиками появляется «Фильтрованный сигнал»
  (другим цветом) — сигнал только в полосе 800–2000 Гц. Скринить когда пик внутри полосы.
  Подпись: «Рис. X. Визуализация сигнала, спектра и фильтрованного канала в реальном времени».

- **`/lab`, сценарий `noise_band`**
  Хаотичный шум и почти чистый синус после полосового фильтра.
  Подпись: «Рис. X. Результат применения полосового фильтра (900–1100 Гц)».

- **`/lab`, сценарий `chirp_sweep`**, момент когда пик посередине FFT
  Самый наглядный скрин для раздела «Спектральный анализ».

#### Мониторинг
- **`/metrics`** (сценарий `full_pipeline`)
  Throughput по топикам, латентность, активные consumer groups.

- **`http://localhost:8099/status`** (JSON)
  Список процессов оркестратора, статус alive/dead.

### Для презентации (слайды)

**Слайд «Демо — осциллограф»**
→ `/lab`, сценарий `chirp_sweep`, момент когда пик FFT посередине.
Крупный скрин на весь слайд. Подпись: «Анализ sweep-сигнала в реальном времени».

**Слайд «Фильтрация»**
→ `/lab`, сценарий `full_pipeline`, когда пик находится внутри полосы фильтра.
Видны три секции: сырой сигнал, спектр, фильтрованный сигнал (фиолетовый).
Подпись: «Полосовой фильтр 800–2000 Гц: сигнал до и после».

**Слайд «Конструктор пайплайна»**
→ `/constructor` → вкладка «Схема», сценарий `multi_signal`.
Разветвлённый граф с двумя каналами.

**Слайд «Топики и данные»**
→ `/topics`, любой сценарий, несколько активных топиков с живыми offset'ами.

**Слайд «Метрики»**
→ `/metrics`, сценарий `full_pipeline`.

## Порядок для живого демо (5 минут)

1. `./scripts/demo.sh` — запустить, дождаться статуса.
2. Открыть `/topics` — показать живые топики, растущие offset'ы.
3. Перейти в `/lab` — показать sweep-синусоиду и FFT (пик едет).
4. Обратить внимание на «Фильтрованный сигнал» — появляется и пропадает.
5. Переключить сценарий: `wave-orchestrator reload --config .../chirp_sweep.yaml`
6. Показать широкий sweep 100–8000 Гц.
7. Перейти в `/constructor` → «Схема» — показать граф.
8. `/metrics` — throughput, латентность.
9. Ctrl+C — всё останавливается чисто.

## Полезные команды

```bash
# Статус оркестратора
wave-orchestrator status

# JSON-статус через API
curl http://localhost:8099/status | python3 -m json.tool

# Посмотреть топики брокера
curl http://localhost:8090/api/topics

# Переустановить integration-компонент (после изменений synth.py)
cd components/integration && pip install -e . -q && cd ../..
```
